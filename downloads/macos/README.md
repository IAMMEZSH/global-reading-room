# macOS 12+

Requires Node.js 20 or newer (`brew install node`).

1. Download `global-reading-room-1.0.0-macos.tar.gz` and extract it.
2. Double-click `Start Global Reading Room.command`.
3. If Gatekeeper blocks the first launch, right-click the file and choose **Open** once.

The launcher keeps Terminal open, checks the Node.js version, starts the server and opens `http://127.0.0.1:7317`. The package works on Apple silicon and Intel Macs.

Checksum: see `SHA256.txt` in this folder.
