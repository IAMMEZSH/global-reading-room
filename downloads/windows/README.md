# Windows 10 / 11 (x64)

Portable, click to run. The package bundles the official Node.js runtime, so nothing is installed and no registry keys are written.

1. Download `global-reading-room-1.0.0-windows-x64.zip` and extract it.
2. Open the extracted folder.
3. Double-click `Start Global Reading Room.vbs`.

The browser opens `http://127.0.0.1:7317` and the first sync begins. Data lives in `data\` beside the launcher. To watch the server log, use `Start Global Reading Room (console).cmd` instead.

Checksum: see `SHA256.txt` in this folder.
