翻译服务

MyMemory 无需注册，适合试用和短文章。长文可能遇到每日额度限制。

DeepL API Free 每月约 50 万字符，翻译质量适合新闻。

多服务资源必须填写区域；免费层每月约 200 万字符。

需在百度翻译开放平台开通“通用文本翻译”服务。

快速填入：

任何兼容 OpenAI /chat/completions 的服务均可。本地 Ollama 可不填密钥。

图片与视频文字

视频：正文里带字幕轨（WebVTT / SRT）的播放器会出现“翻译字幕”按钮；YouTube 等平台会尝试读取平台字幕，若平台拒绝下载，可点“粘贴字幕”把播放器里的字幕或文字稿粘贴进来翻译。
